## Entry format

Each glossary entry in the data file holds: term, level 1 sentence, level 2 explanation, example, diagram id, level 3 link, and the `SOURCES.md` identifier of every source behind the text.

## Sources to look for first

NASA education and kids' pages, NASA Science pages for Mars, orbits, communications and the Sun, ESA education pages. Wikipedia is a last resort. Nothing is added to the data file before the link has been opened and recorded.
